# Ограничения этапа 1

## Не реализовано (осознанно)

- Прямое подключение 4 аккаунтов Avito
- Анализ звонков / транскрибация
- Реальные AI-запросы во внешние сервисы
- Запись в Bitrix (создание дел, смена стадий)
- Telegram-рассылки
- Production deploy без отдельного разрешения
- Интеграция с SQLite `/opt/prosrochka` и `/opt/focusgroup-sla`

## Данные, которые могут быть недоступны

| Область | Поведение |
|---------|-----------|
| Семантика этапов | Без `STAGE_SEMANTIC_ID` won/lost могут показывать «недостаточно данных» |
| CLOSEDATE | Fallback на `date_modify` с пометкой в `data_quality` |
| Полная история стадий | Только наблюдаемые изменения при sync |
| Персональные контакты | Не копируются на этапе 1 |

## Регламент «сделки без движения»

Правила в `StalledRulesConfig` — плейсхолдеры. Не утверждённый SLA компании. В UI используется формулировка «нет следующего запланированного дела».
